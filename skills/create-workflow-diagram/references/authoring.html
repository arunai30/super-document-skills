Content selects slots. CSS computes geometry.

Read the starter's CSS once and retain it in the final HTML. Write the file directly; no preprocessing or runtime. All numbers below are logical column indices, not pixels. Main nodes occupy slots 1 through N in DOM order. Set --columns:N on .canvas. Support nodes use --col:N and share the corresponding main column. Keep the .canvas container: descendants use its cqw units. Modern browsers are required.

Edges: copy only the needed pattern

forward: primary column i to i+1. Set --from:i. Children: span.seg.h, span.arrow.right, span.edge-label. A real relationship is required between each adjacent main node. Label at most about 30 characters.

drop: primary i to support i. Set --from:i. Children: span.seg.v, span.arrow.down, span.edge-label. The support node must exist. Label at most about 30 characters. A read-request arrow points toward the store; it does not depict the data response.

branch: primary i to support j, i != j. Set --from:i;--to:j;--lane:0 or 1. Children: span.seg.v.out, span.seg.h.across, span.seg.v.in, span.arrow.down, span.edge-label. Prefer same-column drop edges; use no more than two branches. Branch lanes may cross other support stems, so split the view if that makes the meaning ambiguous.

feedback: primary i to an earlier primary j, j < i. Set --from:i;--to:j;--lane:0 or 1. Children: span.seg.h.exit, span.seg.v.out, span.seg.h.across, span.seg.v.in, span.seg.h.enter, span.arrow.right, span.edge-label. Travels below the support row and enters the left edge of the target. Use at most two feedback edges with distinct lanes, distinct source columns, and distinct target columns. Shared endpoints would merge their vertical corridors; split the view instead. Feedback labels should fit two short lines.

Connector crossings are not junctions. Avoid branch/feedback combinations with ambiguous crossings. There is no arbitrary graph routing, reverse support edge, support-to-support edge, or precise timing guarantee in this grammar. Omit unrelated components rather than inventing relationships to fit slots.

Readable content

Prefer node titles below 24 characters and a single short qualifier. For 6–7 nodes use a wider desktop page via one shared max-width/min-width change, or split into shorter paths if the reader is on a smaller screen. The default supports a desktop view from 1040px; horizontal overflow below that is intentional, not mobile support. Place details and caveats below the diagram. Keep color-independent labels and contrast. The two themes share all geometry.

Accessible relationships

Manual integrity check

Count main nodes against --columns. Resolve every edge endpoint and support slot. Verify each arrow's direction and claim. Check feedback source greater than target and unique corridors; keep lanes 0 or 1. Remove unused sample nodes and edges. Escape &, <, > and quotes in copied source content. Do not include scripts, forms, SVG, canvas, external fonts, dependencies, or network calls. If a browser is available, review the actual file; otherwise say visual review was unavailable. There is no hidden automated geometry validator.
